## How to Run

1.  **Start Docker containers:**
    ```bash
    docker compose up -d
    ```
2.  **Install Modules:**
```bash
npm run install
```
3.  **Start the application:**
    ```bash
    npm run start:dev
    ```
3.  **View API Documentation:**
    Open your browser and navigate to:
    ```
    http://localhost:3000/api/doc
